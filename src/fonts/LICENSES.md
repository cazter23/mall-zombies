# Font licences

The 25 font families bundled in `files/` (Latin subsets of Google Fonts families, as built by Fontsource) and the licence each is
shipped under. The full licence texts, with each family's copyright notice, are in `licenses/`, copied unchanged from the family's
Fontsource package (`@fontsource/<slug>`, the same source as the font files). Both licences allow bundling and redistributing the
fonts with the game; the game itself is MIT (../../LICENSE), which does not cover these fonts.

A new family: add its licence file here too (tests/typefaces.test.js checks that every family in config/typefaces.js has one).
